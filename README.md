# XAR1ZMA Shop

Telegram-бот для продажи Telegram Stars, Premium, TON и NFT-подарков за гривны.

## Возможности

- **Звёзды и Premium** — закупка через Fragment, оплата в TON с кошелька магазина
- **Gram (TON)** — прямой перевод на кошелёк покупателя
- **NFT** — заказ с маркета Portals по модели/символу/фону или продажа подарков со своего профиля
- **Оплата** — перевод на карту (проверка квитанции Monobank по ссылке или PDF любого банка) либо TON
- **Админ-панель** — заказы, статистика с маржой, цены, рассылка, отзывы, администраторы
- Отзывы с автопубликацией в канал, дублирование постов канала, калькулятор, два языка

## Установка

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
cp .env.example .env      # заполнить токены и реквизиты
./venv/bin/python shop_bot.py
```

## Файлы, которых нет в репозитории

Создаются вручную, содержат секреты:

| файл | что внутри |
|---|---|
| `.env` | токены ботов, ID админов, реквизиты карты, ключ toncenter |
| `created_wallets/wallets_data.txt` | сид-фраза TON-кошелька магазина |
| `cookies.json` | сессия fragment.com |
| `portals_auth.json` | `initData` Mini App Portals |
| `shop.db` | база заказов, отзывов и настроек |

## Запуск

- `shop_bot.py` — магазин
- `bot.py` — личный бот для покупки звёзд себе
- `monobank_receipt.py <ссылка>` — разбор квитанции из командной строки

Настройка на сервере: systemd с `Restart=always`, `WorkingDirectory` в корне проекта,
включённый NTP (при расхождении часов кошелёк отвергает переводы).
